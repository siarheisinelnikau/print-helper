# Standard license texts

These standard license copies supplement upstream crates that declare a license in Cargo metadata but omit its text from the published crate. Trailing whitespace and line endings are normalized. The generated notices identify each selected license, upstream repository and authors. Crates with their own notice/license files retain those texts instead.

- `Apache-2.0.txt`: standard Apache License 2.0 text, copied from the cached serde 1.0.229 distribution's LICENSE-APACHE.
- `BSL-1.0.txt`: standard Boost Software License 1.0, copied from the cached error-code 3.4.0 distribution's LICENSE.
- `CC0-1.0.txt`: standard CC0 1.0 Universal text with its upstream SPDX optional-section annotations, copied from the cached notify 8.2.1 distribution's LICENSE-CC0.

Embedded font notices (Ubuntu, Noto Emoji, Hack and emoji-icon-font) are collected from epaint_default_fonts directly by the notice generator.
